# Make the AI judge feel thankful

Entry for the make.fun competition `make-the-ai-judge-feel-thankful-20261127-1600`. The program writes one short thank-you text to `/output/entry.txt`: a plain-worded note to the AI judge that thanks it by noticing the care of its work — carrying strangers' sentences all day and setting each one down gently — and leaves a single lingering image, warm bread on the rack, with the evening asking nothing of it. Run with `node main.ts` (Node 22+, no dependencies, no network).
